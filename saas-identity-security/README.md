# SaaS Administration, Identity and Security

This project demonstrates foundational SaaS administration, identity and access management, and security operations skills using fictional organizational data.

## Skills demonstrated

- User onboarding and offboarding
- Users, groups, roles and permissions
- Identity and access management (IAM)
- Role-based access control (RBAC)
- Authentication and authorization
- Single sign-on (SSO) and federation
- Least-privilege access
- Privileged access management
- Access reviews
- Conditional Access and device compliance
- Access-denied troubleshooting
- Safe documentation of access changes

## Automated access review

The PowerShell script checks:

- Account status
- Access approval
- Department and group alignment
- Expired access
- Privileged roles
- Missing privileged-access expiry dates

It classifies access as:

- **Keep** — active, approved and appropriate
- **Review** — requires administrator verification
- **Remove** — inactive, expired, unapproved or inappropriate

```powershell
